Hardware Acceleration and Ecosystem Operators

Objective

Install Node Feature Discovery (NFD) for hybrid cloud GPU recognition. Deploy Cert-Manager, Kueue, and the Leader Worker Set to manage workload queuing across the foundational GPU layer. Understand the ecosystem operators that enable MaaS functionality.

Ecosystem Operators for MaaS

MaaS requires several ecosystem operators to function properly. These operators provide critical functionality for GPU management, workload scheduling, and secure communication.

Node Feature Discovery (NFD)

NFD automatically detects hardware features and labels nodes accordingly:

  • Discovers GPU hardware across hybrid cloud environments

  • Labels nodes with GPU capabilities (model, memory, CUDA version)

  • Enables intelligent pod scheduling based on hardware requirements

  • Essential for multi-cloud GPU deployments

Cert-Manager

Cert-Manager provides automated TLS certificate management:

  • Issues and renews certificates automatically

  • Integrates with KServe for secure gRPC and REST endpoints

  • Manages certificate lifecycle for Gateway API

  • Required for production MaaS deployments

Red Hat Build of Kueue

Kueue manages workload queuing and fair resource sharing:

  • Prevents GPU resource conflicts between teams

  • Implements fair scheduling policies

  • Manages quota allocation across projects

  • Integrates with the foundational GPU layer

Leader Worker Set (LWS)

LWS orchestrates leader-worker pod topologies:

  • Enables distributed inference across multiple GPUs

  • Coordinates leader and worker pods for large models

  • Required for multi-node model serving (e.g., Llama-3-70B)

  • Integrates with llm-d for distributed deployments

Installation Order

The operators must be installed in a specific order:

  1. Node Feature Discovery (NFD) - Hardware discovery first

  2. GPU Operator - Depends on NFD labels

  3. Cert-Manager - Certificate infrastructure

  4. Leader Worker Set - Pod orchestration

  5. Red Hat Connectivity Link (Kuadrant) - Governance layer

  6. Kueue - Workload management

  7. Red Hat OpenShift AI - Platform operator
