Quick Reference: 3.3 MaaS Commands

Keep these CLI commands handy when investigating the MaaS stack.

Goal Command

List MaaS deployments

oc get llminferenceservice -n <namespace>

Check Tier Mappings

oc get configmap tier-to-group-mapping -n redhat-ods-applications -o yaml

Verify MaaS API Health

oc get pods -n redhat-ods-applications -l app=maas-api

Test Token Auth (CLI)

curl -I -H "Authorization: Bearer $MAAS_TOKEN" https://maas.<domain>/v1/models

Check GPU Availability

oc get nodes -l nvidia.com/gpu.present=true

Verify RoCE Network

oc get networkattachmentdefinitions -n <namespace>
